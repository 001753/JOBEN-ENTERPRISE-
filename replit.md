# JOBEN ENTERPRISE

## Project overview

JOBEN ENTERPRISE adalah platform compliance automation dan trust management.
Dokumen kebutuhan kanonik berada di `DOC/PRD-JOBEN-ENTERPRISE.md`. Roadmap
engineering yang memecah pekerjaan dari Foundation sampai GA berada di
`DOC/BUILD-ROADMAP.md`.

Repository saat ini berisi baseline PRD dan belum berisi aplikasi live,
connector production, customer data, atau hasil screening nyata.

## User preferences

- Prioritaskan build berdasarkan kebenaran data, keamanan, isolasi tenant, dan
  operasional; jangan menukar correctness dengan UI atau kecepatan demo.
- Capability yang belum memiliki bukti harus ditampilkan sebagai belum siap,
  bukan disamarkan dengan sample data atau optimistic state.
- Pertahankan stack dan struktur PRD kecuali ada RFC/keputusan eksplisit.
